# NextTrack Pilot Checklist

## Before the Session

- [ ] Correct prototype version is running.
- [ ] Git tag / commit recorded.
- [ ] `/evaluation` loads successfully.
- [ ] Study Mode loads successfully.
- [ ] Rock context works.
- [ ] Hip-Hop context works.
- [ ] Country context works.
- [ ] Spotify links open correctly.
- [ ] Participant code prepared.
- [ ] Questionnaire available.
- [ ] Start time recorded.

## During the Session

### Participant Understanding

- [ ] Participant understands the recent listening context.
- [ ] Participant understands Set A and Set B are recommendations.
- [ ] Participant understands that there is no correct answer.
- [ ] Participant can use Spotify links without assistance.

### Interface

- [ ] Study context can be selected.
- [ ] Three seed tracks are displayed.
- [ ] Generate Comparison button works.
- [ ] Set A contains five recommendations.
- [ ] Set B contains five recommendations.
- [ ] No exploration value is displayed.
- [ ] No recommendation score is displayed.
- [ ] No genre label is displayed in study results.
- [ ] No JavaScript errors occur.

### Counterbalancing

- [ ] Odd participant code tested.
- [ ] Even participant code tested.
- [ ] A/B conditions reverse as expected.

## After the Session

- [ ] End time recorded.
- [ ] Total duration recorded.
- [ ] Difficult instructions identified.
- [ ] Difficult questionnaire questions identified.
- [ ] Interface problems recorded.
- [ ] Spotify availability problems recorded.
- [ ] Participant feedback recorded.
- [ ] Required changes classified as critical or optional.
