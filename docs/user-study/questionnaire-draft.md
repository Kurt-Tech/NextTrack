# NextTrack User Evaluation Questionnaire

## Purpose

This questionnaire evaluates the perceived quality of music
recommendations generated by NextTrack.

Participants will compare two recommendation sets generated from the
same recent listening context. The settings used to generate Set A and
Set B are intentionally hidden.

There are no correct or incorrect answers. Responses should reflect
the participant's personal judgement of the recommendation sets.
