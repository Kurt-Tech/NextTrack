# NextTrack Formal User Evaluation Analysis Plan

## Experimental Conditions

Low exploration:
exploration_level = 0.00

High exploration:
exploration_level = 1.00

## Counterbalancing

Odd participant codes:
Set A = Low exploration
Set B = High exploration

Even participant codes:
Set A = High exploration
Set B = Low exploration

The displayed Set A / Set B labels will be decoded to Low / High
exploration before aggregate analysis.

## Evaluation Dimensions

For each context and condition:

1. Perceived relevance
2. Perceived diversity
3. Discovery value
4. Overall satisfaction

Each is measured using a five-point response scale.

Participants also indicate:

- preferred recommendation set;
- optional reason for preference.

## Aggregate Analysis

For Low and High exploration calculate:

- mean perceived relevance;
- mean perceived diversity;
- mean discovery value;
- mean satisfaction.

Calculate recommendation-set preference counts for:

- Low exploration;
- High exploration;
- No preference.

Results will also be inspected separately for:

- Rock;
- Hip-Hop;
- Country.

## Interpretation

The user evaluation is exploratory and will be interpreted alongside
the project's offline technical evaluation.

The study will not claim population-level statistical generalisability
from the small participant sample.
